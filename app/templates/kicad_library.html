Use the library as a KiCad HTTP library

For KiCad 8 and later: the parts appear in the symbol chooser, one library for each category. The Remote Symbols panel needs KiCad 10.

1. Have the drawings

An HTTP library gives KiCad each part's data, not its drawings: the symbol and footprint a part names are found in your own library tables. So check the library out, and add its libraries under the names it uses.

  1. Clone {% for source in sources %} {{ source.url }}{% if not loop.last %} and {% endif %} {% endfor %} somewhere on your computer, and pull it now and then: new drawings arrive that way.
  2. In KiCad, Preferences → Configure Paths: set KICAD_LIBRARY_DIR to that folder, and the variable its footprints name their 3D models with to its 3dmodels folder.
  3. Add its symbol and footprint libraries, under the same names. Its sym-lib-table and fp-lib-table list them; the libraries uploaded here are added to those files too.

2. Add the HTTP library

{% endif %}

Then in KiCad, Preferences → Manage Symbol Libraries: add the file as a library of the type HTTP. Parts are read again after a minute; a new category shows after KiCad is restarted. The address it reads is {{ root_url }}.
